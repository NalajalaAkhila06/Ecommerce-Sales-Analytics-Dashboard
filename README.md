# 🛒 E-Commerce Sales Analytics Dashboard using Machine Learning & Power BI

> An end-to-end Data Analytics and Machine Learning project that transforms raw e-commerce sales data into actionable business insights using Python, Google Colab, Scikit-learn, and Microsoft Power BI.

## 📌 Project Overview

This project demonstrates a complete **Business Intelligence and Machine Learning workflow** for an e-commerce dataset. It includes data preprocessing, predictive analytics, customer segmentation, and interactive dashboard development.

The project helps businesses:
- 📈 Analyze sales and profit trends
- 🤖 Predict future sales using Machine Learning
- 👥 Segment customers based on purchasing behavior
- 📊 Monitor business performance using interactive dashboards
- 💡 Generate data-driven business recommendations

---

## 🎯 Objectives

- Analyze historical e-commerce sales data
- Predict future sales using Machine Learning
- Perform customer segmentation using clustering
- Build interactive Power BI dashboards
- Support better business decision-making through analytics
